# Ковчег: Последний рейс (v3)

Что нового по сравнению с v2:
- Исправлена ошибка, из-за которой партия вообще не запускалась (движок игры был недоступен для кнопки «Начать» и для опроса сервера).
- Ведущий не играет: создаёт комнату, показывает QR, выбирает критерии партии, запускает игру и управляет ею.
- Критерии партии (в лобби, сохраняются сразу): название, макс. игроков, дней до берега, таймер дня, число людоедов, Сообщник, запасы, тайные связи.
- Ведущий может убрать игрока из лобби кнопкой «УБРАТЬ».
- Старт: достаточно 6 игроков, «Я готов» не обязателен.
- Партия переживает обновление вкладки ведущего (слепок хранится в Upstash).

## Как выложить обновление
1. GitHub → репозиторий kovcheg → Add file → Upload files.
2. Перетащите `index.html` и папку `api` (внутри `kovcheg.js`). Они заменят старые. Commit changes.
3. Vercel сам пересоберёт сайт за 1–2 минуты. Переменные окружения и базу Upstash трогать не нужно.
